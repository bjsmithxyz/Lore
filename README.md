# Lore

A local-first visual story bible for building fiction worlds as an explorable graph.

## Run locally

```bash
npm install
npm run dev
```

Create nodes, connect relationships, edit notes, and export projects as JSON or Markdown. Projects autosave locally in the browser.

## Build

```bash
npm run build
```

The app is configured to deploy to GitHub Pages from `main` once Pages is enabled for the repository:

https://bjsmithxyz.github.io/Lore/

Built with React, TypeScript, Vite, and React Flow.
